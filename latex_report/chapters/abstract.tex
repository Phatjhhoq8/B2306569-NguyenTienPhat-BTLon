The project ``Developing an online book borrowing system - CTU eLibrary'' was conducted to support the process of looking up, borrowing, returning, and managing books in the library on a web platform. The system provides an interface for readers to search for books, view book details, add books to the borrow cart, create borrow slips, track borrowing and returning history, pay borrowing fees, fines, and register for membership packages. Additionally, the system also has an administration portal for library staff and managers to process book titles, book copies, readers, staff, borrow slips, fines, finance, discount codes, membership packages, and website content.

Technically, the system is built on a client--server model. The frontend utilizes Vue 3, Vite, Pinia, Vue Router, and Tailwind CSS. The backend uses Node.js, Express.js, MongoDB, and Mongoose. The authentication mechanism is implemented using JWT combined with HTTP-only cookies, with role-based authorization for readers, staff, and managers. In addition to the main business functions, the system also integrates an AI assistant to support readers in finding books and consulting on membership packages.

The results show that the system meets the basic requirements of an online book borrowing website, while expanding many management functions suitable for actual library operations.
